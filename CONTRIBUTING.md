# Contribuer

Toutes les règles sont dans le [guide de développement](docs/DEVELOPPEMENT.md). L'essentiel :

- **pnpm** uniquement ; `pnpm run ci` doit passer avant chaque commit.
- **Commits** : `type(périmètre): sujet` en français, au présent de l'impératif, un commit par intention (chapitre 2 du guide).
- **Branches** courtes `type/sujet`, fusion par pull request, jamais de réécriture de l'historique publié.
- **Sécurité** : aucun secret ni donnée personnelle réelle dans le dépôt (chapitre 4).
- **Avancement** : mettre à jour [docs/ETAT_DU_PROJET.md](docs/ETAT_DU_PROJET.md) dans chaque lot livré.
