## Project rules

- All colors/sizes come from the primitive→semantic→component CSS variables in src/styles.css (mirrors design-tokens.json); only the primitive block changes for a new charter.
- UI reads permissions from src/lib/permissions.ts (stand-in for the server endpoint); never hardcode role checks in components.
- Data is in-memory demo data (src/lib/mock, src/lib/store.ts) until the real backend API exists.
- Leaflet is only imported via React.lazy after mount (SSR-safe).
- **Hébergement** : Vercel + Nitro `preset: "vercel"` + `vercel.json`. Ne jamais repasser à `cloudflare-module` (ou un autre preset) sans aligner `vercel.json` et la doc dans le même commit. TanStack Start ne produit pas de dossier `dist` : la sortie attendue est `.vercel/output`. Vérifier avec `pnpm check:host`. Dans le Dashboard, laisser les overrides Build/Output/Install **OFF** (le placeholder `dist` est trompeur ; ne pas le forcer).
- **Node sur Vercel** : pin LTS **22.x** (`package.json` → `engines.node: "22.x"`, `.nvmrc` → `22`, Project Settings → Node.js Version **22.x`). Jamais de plage ouverte (`>=22`) : Vercel la résout vers le dernier major disponible (ex. 24.x). Les patchs de sécurité du runtime géré sont appliqués par Vercel.
- **Build Vercel / `VITE_DEMO_MODE`** : la valeur `true`|`false` doit être commitée dans `.env.production` (lu par Vite et `scripts/check-env.mjs`). Ne jamais compter sur `vercel.json` → `env` seul : cette clé n'alimente que le runtime des fonctions serverless, pas la phase install/build. `pnpm check:host` vérifie la présence de la variable dans `.env.production`.
- **CSP** (`vercel.json`) : politique en **Report-Only** (`Content-Security-Policy-Report-Only`) — les violations s'affichent dans la console mais ne bloquent rien. Tuiles Esri (`server.arcgisonline.com` : World Street Map + World Imagery) autorisées ; pas de `tile.openstreetmap.org` (politique d'usage OSM.org) ; `media-src 'self'` ; `frame-src 'none'`. **Ne pas** autoriser `vercel.live` : pour le prototype, désactiver la barre Feedback / Vercel Toolbar dans le Dashboard (Settings → Toolbar / Comments) afin d'éviter bruit CSP, iframes et sons `data:audio` + AbortError `play()`/`pause()`. Passer en CSP bloquante seulement quand les scripts inline SSR auront un nonce.
- **i18n** : aucun texte visible en dur dans les écrans une fois extraits ; tout passe par `src/lib/i18n/` (chapitre 6 de `docs/DEVELOPPEMENT.md`). Wolof jamais traduit automatiquement.
