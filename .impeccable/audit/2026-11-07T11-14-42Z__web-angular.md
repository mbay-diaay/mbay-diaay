## Detailed Findings

### [P1] Dialogues sans piège de focus ni Escape
- **Location :** `web-angular/src/app/shared/ui/dialog.component.ts` ; dialogs ad hoc `equipe.page.ts`, `reunions.page.ts`
- **Category :** Accessibility
- **Impact :** Clavier / lecteur d’écran : focus reste derrière l’overlay ; Escape ne ferme pas `ui-dialog`
- **WCAG :** 2.1.2, 2.4.3
- **Recommendation :** Focus trap + restore, `keydown.Escape`, `aria-modal`, focus initial sur le panneau
- **Suggested command :** `/impeccable harden web-angular/src/app/shared/ui/dialog.component.ts`

### [P1] Recherche / filtre alertes sans nom accessible
- **Location :** `web-angular/src/app/pages/qualite.alertes.page.ts` (~L56–65)
- **Category :** Accessibility
- **Impact :** Input search et `<select>` status sans `aria-label` / `<label>`
- **WCAG :** 1.3.1, 4.1.2
- **Recommendation :** Réutiliser le pattern `aria-label` + i18n des autres listes
- **Suggested command :** `/impeccable harden web-angular/src/app/pages/qualite.alertes.page.ts`

### [P1] Aucune prise en charge `prefers-reduced-motion`
- **Location :** `web-angular/src/styles.css` (`mbay-animate-*`) ; `animate-spin` imports
- **Category :** Accessibility
- **Impact :** Sheets / toasts animent toujours ; risque pour utilisateurs vestibulaires
- **WCAG :** 2.3.3
- **Recommendation :** `@media (prefers-reduced-motion: reduce)` → opacity courte ou instantané, garder le changement d’état
- **Suggested command :** `/impeccable animate web-angular` (avec variante reduced)

### [P1] Bundle i18n monolithique (~2.4 Mo / ~340 Ko gzip)
- **Location :** chunk `locale.service-*.js` ; `src/lib/i18n/translate.ts` importe `fr` + `wo` + tous les modules messages (y compris M2–M5 absents du menu)
- **Category :** Performance
- **Impact :** Coût réseau / parse sur chaque session (terrain 3G)
- **Recommendation :** Split lazy par locale et/ou par domaine M1 ; exclure messages hors M1 du bundle Angular
- **Suggested command :** `/impeccable optimize web-angular/src/lib/i18n`

### [P2] Menus ⋯ sous 44×44 px
- **Location :** `appareils.page.ts`, `utilisateurs.page.ts` (`h-8 w-8` sans `pointer-coarse:size-touch`)
- **Category :** Responsive
- **Impact :** Cibles trop petites au doigt (terrain)
- **Recommendation :** Aligner sur `ui-button` icon (`pointer-coarse:size-touch`)
- **Suggested command :** `/impeccable adapt web-angular`

### [P2] `chip-filter-sm` / toggles vue à ~32 px
- **Location :** `styles.css` `@utility chip-filter-sm` ; toggles liste/calendrier `reunions.page.ts`
- **Category :** Responsive
- **Impact :** Sur pointeur grossier, sous le minimum 48 px produit
- **Recommendation :** `pointer-coarse:h-touch` sur chip-filter / toggles
- **Suggested command :** `/impeccable adapt web-angular`

### [P2] Placeholder FR en dur (imports)
- **Location :** `imports.page.ts` — `', lot…'`
- **Category :** Implementation Integrity / i18n
- **Impact :** Chaîne hors `i18n/` (règle projet)
- **Recommendation :** Extraire clé messages
- **Suggested command :** `/impeccable clarify web-angular/src/app/pages/imports.page.ts`

### [P2] Page d’erreur Nitro hors charte
- **Location :** `web-angular/src/lib/error-page.ts` (`#fafafa`, `#111`, system-ui)
- **Category :** Theming
- **Impact :** Fallback hors tokens CRADESC (rare)

## Patterns & Systemic Issues

1. **Modales ad hoc vs `ui-dialog`** — plusieurs pages dupliquent `role="dialog"` sans le kit partagé → risque a11y récurrent.
2. **Touch targets** — pattern `pointer-coarse:h-touch` bien démarré (auth, shell, chips dossiers) mais **non généralisé** (menus ⋯, chip-sm, alertes).
3. **i18n eager** — `translate.ts` tire tout le dictionnaire FR (+ WO) et des domaines hors M1 → coût systématique.

## Positive Findings

- Tokens primitive → semantic → component ; detector clean
- Chip-rails scrollables (dossiers / coopératives / équipe / qualité)
- Nombreux `aria-label` / `aria-pressed` sur filtres et recherches M1
- Pastilles statut = couleur + libellé
- Leaflet / Chart / xlsx en chunks séparés
- Cibles 48 px documentées (`--size-touch-min`) et utilisées sur login / shell
